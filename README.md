# striphive

Strip encode/decode helpers for hive payloads in pipelines.

**Site:** https://theworker02.github.io/striphive/

## Install / run

```bash
git clone https://github.com/theworker02/striphive.git
cd striphive
node src/cli.js
node --test
```
